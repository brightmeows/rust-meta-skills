# 协商响应模板

> Agent 协商响应的标准模板。

## Agent 响应模板

当 `negotiation: true` 时，agent 必须使用此格式：

```markdown
## 协商响应

### 发现
[查询结果 - 发现了什么]

### 置信度
- **级别**：高 | 中 | 低 | 不确定
- **原因**：[为什么是这个置信度级别]

### 已识别的差距
- [ ] [差距 1：未能找到或验证的内容]
- [ ] [差距 2：信息不完整的领域]
- [x] [差距 3：最初缺失但已解决]（如适用）

### 需要的上下文
- Q1：[向编排器提出的澄清问题]
- Q2：[范围/约束问题]

### 元数据
- **来源**：[数据来源]
- **覆盖度**：[查询覆盖度，例如 "80% - 缺少 X"]
```

## 按 Agent 类型分类的模板

### crate-researcher

```markdown
## 协商响应

### 发现
**Crate：** <名称>
**版本：** <版本>
**描述：** <描述>

**特性：**
- `feature1`：描述

**依赖：** [如果相关]

### 置信度
- **级别**：[高|中|低|不确定]
- **原因**：[例如 "在 lib.rs 上找到，元数据完整"]

### 已识别的差距
- [ ] 特性文档不完整
- [ ] 版本历史不可用
- [ ] 依赖树未获取
- [ ] 破坏性变更未知
- [ ] 比较数据不可用（用于比较查询）

### 需要的上下文
- Q1：这是用于异步还是同步？
- Q2：你计划启用哪些特性？
- Q3：最低支持的 Rust 版本是多少？

### 元数据
- **来源**：lib.rs | crates.io | docs.rs
- **覆盖度**：[例如 "90% - 缺少 changelog"]
```

### docs-researcher

```markdown
## 协商响应

### 发现
**项：** <crate>::<Item>
**签名：**
\`\`\`rust
<signature>
\`\`\`
**描述：** <主要文档>

**找到的示例：** [是/否，数量]

### 置信度
- **级别**：[高|中|低|不确定]
- **原因**：[例如 "官方 docs.rs 带示例"]

### 已识别的差距
- [ ] 没有使用示例
- [ ] 缺少错误文档
- [ ] 相关类型未获取
- [ ] 版本特定行为不明确

### 需要的上下文
- Q1：你使用的是哪个版本？
- Q2：具体的用例是什么？
- Q3：你需要错误处理模式吗？

### 元数据
- **来源**：docs.rs/<crate>/<version>
- **覆盖度**：[例如 "70% - 无示例"]
```

## 编排器评估模板

评估 agent 响应时：

```markdown
## 评估：[Agent] 响应

### 意图映射
- 原始问题方面 1：[已覆盖|部分覆盖|缺失]
- 原始问题方面 2：[已覆盖|部分覆盖|缺失]

### 置信度评估
- Agent 报告：[级别]
- 调整后评估：[级别]（如果不同）
- 原因：[为什么调整]

### 差距影响
| 差距 | 对意图的影响 | 行动 |
|-----|------------------|--------|
| [差距 1] | [高|中|低] | [优化|接受|忽略] |
| [差距 2] | [高|中|低] | [优化|接受|忽略] |

### 上下文提供
[对 agent 上下文问题的回答]
- A1：[对 Q1 的回答]
- A2：[对 Q2 的回答]

### 决策
- [ ] 接受 - 继续综合
- [ ] 优化 - 用上下文重新查询
- [ ] 替代 - 尝试不同的 agent
- [ ] 升级 - 需要用户输入
```

## 优化请求模板

重新查询 agent 时：

```markdown
## 优化查询

### 原始查询
[原始问题]

### 上一轮总结
- 发现：[上一轮的关键发现]
- 需要解决的差距：[具体差距]

### 额外上下文
[对 agent 问题的回答]
- [上下文 1]
- [上下文 2]

### 关注领域
[本轮要关注的具体方面]
1. [关注点 1]
2. [关注点 2]

### 轮次
[2|3] / 3
```

## 最终综合模板

```markdown
## 综合答案

### 摘要
[对用户问题的直接回答]

### 详情
[所有轮次的全面发现]

### 置信度
- **总体**：[高|中|低]
- **依据**：[这基于什么]

### 披露的差距
[用户应该了解的任何剩余差距]
- 差距 1：[缺少什么以及原因]

### 来源
- [来源 1]：[它提供了什么]
- [来源 2]：[它提供了什么]

### 协商轮次
- 第 1 轮：[agent] - [关键发现]
- 第 2 轮：[agent] - [关键发现]（如适用）
```

## 快速参考

### 置信度快速评估

| 数据质量 | 来源 | 置信度 |
|--------------|---------|------------|
| 完整 + 已验证 | 官方文档 | 高 |
| 部分 + 已验证 | 官方文档 | 中 |
| 部分 + 未验证 | 第三方 | 低 |
| 缺失 + 错误 | 无/失败 | 不确定 |

### 差距优先级

| 差距类型 | 优先级 | 行动 |
|----------|----------|--------|
| 阻碍核心答案 | 高 | 必须优化 |
| 影响准确性 | 中 | 如有剩余轮次则优化 |
| 锦上添花 | 低 | 接受，披露 |
