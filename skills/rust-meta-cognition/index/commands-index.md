| /achievement | `[list\|stats\|reset]` | 查看编码成就、统计和进度追踪... |

| /audit | `` | 使用多工具执行重量级安全审计... |
| /cache-clean | `` | 清理缓存的 Rust 文档... |
| /cache-status | `` | 显示缓存的 Rust 文档状态... |
| /clean-crate-skills | `` | 移除动态生成的 crate skill... |

| /create-skills-via-llms | `` | 从 llms.txt 为 Rust crate 创建 skill... |
| /docs | `` | 获取 Rust crate 或标准库的 API 文档... |

| /unsafe-review | `` | Unsafe Rust 代码块的交互式审查... |
| /update-crate-skill | `` | 强制使用最新文档重新生成 crate skill... |
